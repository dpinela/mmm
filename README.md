This repository a set of tools to help run multiworld (as in the Hollow Knight
multiworld) randomizers:

- [Isthmus][]: a multiworld client that allows Archipelago clients to join a multiworld game
- [Atoll][]: a multiworld server with async capabilities (much like Archipelago)

[Isthmus]: ./cmd/isthmus/README.md
[Atoll]: ./cmd/atoll/README.md
